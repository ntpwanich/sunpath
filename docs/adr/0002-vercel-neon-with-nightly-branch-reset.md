# Deploy บน Vercel + Neon และรีเซ็ตข้อมูล demo ทุกคืนด้วย Neon branch

SunPath เป็นชิ้นงาน portfolio ที่ต้องเปิดจากลิงก์ได้ตลอดหลายปีโดยไม่มีค่าใช้จ่ายต่อเนื่อง และต้องทนต่อการที่ผู้เข้าชมแก้ข้อมูลเล่นจนเละ เราเลือก Vercel + Neon เพราะฟรีในระดับการใช้งานนี้ ไม่ต้องดูแลเซิร์ฟเวอร์ และ Neon สร้าง branch ของฐานข้อมูลได้ในไม่กี่วินาที เราจึงเก็บ branch ต้นแบบที่บรรจุ demo data ไว้ แล้วให้ cron รีเซ็ต branch ที่ใช้งานจริงกลับไปหาต้นแบบทุกคืน แทนการเขียน script drop-and-seed เอง

**ทางเลือกที่ปฏิเสธ:** Supabase — ฟรีเหมือนกันแต่หยุดโปรเจกต์อัตโนมัติเมื่อไม่มีการใช้งาน 7 วัน ซึ่งทำให้ลิงก์ portfolio ตายเงียบโดยไม่มีใครรู้ Railway/Render — เสถียรกว่าแต่มีค่าใช้จ่ายรายเดือนตลอดไป VPS ที่ดูแลเอง — คุมได้มากที่สุดแต่กลายเป็นภาระ ops ที่ไม่เพิ่มคุณค่าให้ portfolio

**ผลข้างเคียงที่ยอมรับ:** compute ของ Neon หลับเมื่อไม่มีการใช้งานราวห้านาที ผู้เข้าชมคนแรกจะเจอหน่วงราวหนึ่งวินาที บรรเทาด้วย cron ping เป็นระยะ

นอกจากนี้ repo จะมี `docker-compose.yml` ที่รันระบบทั้งชุดได้ในเครื่อง เพื่อรองรับการเล่าว่าระบบย้ายไปติดตั้งบนเซิร์ฟเวอร์ของลูกค้าได้ โดยไม่ต้องจ่ายค่า VPS จริง
