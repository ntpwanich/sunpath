# Next.js เป็นทั้ง frontend และ backend โดยแยกชั้น domain ออกจาก framework

SunPath เป็นระบบเดียว ทีมเดียว ผู้ใช้หลักสิบคน การแยก backend ออกเป็นบริการต่างหากจะเพิ่ม deploy อีกก้อน, CORS, auth ข้ามโดเมน และ latency โดยไม่ได้แก้ปัญหาอะไรที่มีอยู่จริง เราจึงใช้ Next.js App Router ตัวเดียว — Server Components สำหรับอ่าน, Server Actions สำหรับเขียน, Route Handlers สำหรับ webhook รับ lead จากภายนอก

เงื่อนไขที่ผูกมากับการตัดสินใจนี้: business logic ทั้งหมดอยู่ใต้ `src/server/` ที่ไม่ import อะไรจาก React หรือ Next เลย Server Action เป็นเพียงเปลือกบางที่ validate input แล้วเรียก domain ทำให้กติกาทางธุรกิจ (การคัดกรอง lead, การมอบหมายงาน, SLA, การคำนวณขนาดระบบ) ทดสอบได้โดยไม่ต้องรัน framework และย้ายออกไปไว้หลัง API แยกได้ภายหลังถ้าจำเป็น

**กติกาที่ต้องรักษาไว้เพื่อให้ข้อตกลงนี้เป็นจริง**

*เวลาเป็น input ไม่ใช่สภาพแวดล้อม* — ฟังก์ชันใน domain ห้ามเรียก `new Date()` เอง ต้องรับ `now: Date` เข้ามาเสมอ และ schema ห้ามใช้ `@default(now())` กับฟิลด์ใดก็ตามที่ business logic อ่าน (`createdAt`, `contactedAt`, `stageChangedAt`, วันที่ออกใบเสนอราคา) ฟิลด์เหล่านั้นต้องถูกเขียนจากชั้น application เสมอ ใช้ค่าตั้งต้นจากฐานข้อมูลได้เฉพาะฟิลด์ที่ไม่มีใครตัดสินใจจากมัน
ทั้งระบบนี้ตัดสินด้วยเวลา — เลยเส้นตายหรือยัง เงียบมากี่วัน ปิดได้กี่รายเดือนนี้ ถ้าเวลาถูกสร้างขึ้นข้างในฟังก์ชันหรือข้างในฐานข้อมูล จะเขียน test ที่พิสูจน์กติกาเหล่านั้นไม่ได้เลย และ script สร้างข้อมูลตัวอย่างซึ่งต้องปักหมุดวันที่ย้อนหลังเก้าเดือนก็จะทำงานไม่ได้

*ผลลัพธ์ที่ผิดพลาดได้เป็นค่าที่คืนกลับมา ไม่ใช่ exception* — ใช้ discriminated union `Result<T, E>` ที่ประกาศเองราวสิบห้าบรรทัด ไม่ดึงไลบรารี effect system เข้ามา งานใน domain ชั้นนี้เป็นฟังก์ชันบริสุทธิ์ที่รับตัวเลขกับ enum แล้วคืนคำตัดสิน ไม่มี IO ไม่มี async ไม่มีการจัดการทรัพยากร ซึ่งเป็นสิ่งที่ effect system มีไว้แก้ การดึงมันเข้ามาจะทำให้ Server Action ไม่ใช่เปลือกบางอีกต่อไป เพราะต้องมีจุดแปลงกลับทุกจุด

**โครงไฟล์ที่ทำให้ข้อตกลงนี้บังคับได้** (เพิ่มตอน scaffold)

```
src/app/            หน้าและ Server Action — เรียกผ่าน use-case เท่านั้น
src/server/domain/  ฟังก์ชันบริสุทธิ์ ห้าม import react, next, @prisma/client
src/server/use-cases/   ประกอบ domain เข้ากับฐานข้อมูล คุม transaction — เป็นชั้นที่ integration test ยิง
src/server/infra/   Prisma, EmailSender, Vercel Blob
```

ขอบเขตนี้ถูกบังคับด้วย `no-restricted-imports` ใน `eslint.config.mjs` ไม่ใช่ข้อตกลงในหัว ละเมิดแล้ว CI แดง
