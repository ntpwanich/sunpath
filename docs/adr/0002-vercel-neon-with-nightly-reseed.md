# Deploy บน Vercel + Neon และสร้างข้อมูล demo ใหม่ทุกคืนด้วย seed script

SunPath เป็นชิ้นงาน portfolio ที่ต้องเปิดจากลิงก์ได้ตลอดหลายปีโดยไม่มีค่าใช้จ่ายต่อเนื่อง และต้องทนต่อการที่ผู้เข้าชมแก้ข้อมูลเล่นจนเละ เราเลือก Vercel + Neon เพราะฟรีในระดับการใช้งานนี้และไม่ต้องดูแลเซิร์ฟเวอร์ แล้วให้ cron ของ Vercel ลบข้อมูลทิ้งและ **รัน seed script ใหม่ทุกคืน** โดยส่งวันที่ของคืนนั้นเข้าไปเป็นจุดอ้างอิง

**ทำไมไม่ใช้ Neon branch reset ซึ่งเป็นวิธีที่ตรงกว่า:** Neon รีเซ็ต branch กลับไปหา branch ต้นแบบได้จริงในไม่กี่วินาที แต่มันคืนข้อมูลเดิมแบบ byte ต่อ byte รวมถึง timestamp ที่แช่แข็งอยู่กับวันที่สร้าง branch นั้น ระบบนี้ตัดสินแทบทุกอย่างด้วยเวลา — งานไหนเลยเส้นตาย ใบเสนอราคาใบไหนเงียบเกินเจ็ดวัน เดือนนี้ปิดได้กี่ราย ช่างมีคิวอะไรสัปดาห์นี้ ถ้าใช้ branch reset พอผ่านไปสามเดือน dashboard จะแสดงว่าทุกงานเลยเส้นตายและไม่มียอดปิดเลยสักราย ปฏิทินคิวสำรวจจะว่างเปล่า ลิงก์ portfolio จะยังเปิดได้แต่ไม่มีอะไรให้ดู ซึ่งเป็นความล้มเหลวที่เงียบกว่าการที่มันพังไปเลย
seed script ต้องเขียนอยู่แล้วเพื่อสร้างข้อมูลตัวอย่างชุดแรก การให้มันรับวันที่อ้างอิงเข้ามาแล้วเรียกซ้ำทุกคืนจึงแทบไม่มีต้นทุนเพิ่ม และได้ demo ที่สดใหม่ทุกเช้าแทน

**ทางเลือกที่ปฏิเสธ:** Supabase — ฟรีเหมือนกันแต่หยุดโปรเจกต์อัตโนมัติเมื่อไม่มีการใช้งาน 7 วัน ซึ่งทำให้ลิงก์ portfolio ตายเงียบโดยไม่มีใครรู้ Railway/Render — เสถียรกว่าแต่มีค่าใช้จ่ายรายเดือนตลอดไป VPS ที่ดูแลเอง — คุมได้มากที่สุดแต่กลายเป็นภาระ ops ที่ไม่เพิ่มคุณค่าให้ portfolio

**ข้อจำกัดของแผนฟรีที่ผูกมากับการตัดสินใจนี้**

- Vercel Hobby ให้ cron ถี่ที่สุดวันละครั้ง และเวลาที่ยิงจริงคลาดเคลื่อนได้ถึง 59 นาที — พอดีกับการรีเซ็ตรายคืน แต่แปลว่าไม่มีทางทำ cron ที่ถี่กว่านั้นได้เลย
- Vercel Hobby ตัด function ที่ 300 วินาที — seed script ต้องเขียนแบบ batch insert ไม่ใช่วนเขียนทีละแถว
- Neon แผนฟรีให้ 0.5 GB ต่อโปรเจกต์ — เป็นเหตุผลหนึ่งที่รูปถ่ายผลสำรวจไม่ได้เก็บในฐานข้อมูล ดู [ADR 0005](./0005-survey-photos-split-between-permanent-and-disposable-storage.md)
- Neon แผนฟรีให้ 100 CU-hours ต่อเดือน ขณะที่เดือนหนึ่งมี 730 ชั่วโมง จึงเป็นไปไม่ได้ที่จะปลุก compute ไว้ตลอด และปิด autosuspend ก็ไม่ได้บนแผนฟรี — compute จะหลับหลังไม่มีการใช้งานราวห้านาที ผู้เข้าชมคนแรกจะเจอหน่วงราวหลักร้อยมิลลิวินาที ซึ่งเรายอมรับและไม่พยายามบรรเทาด้วยการ ping

**ความเสี่ยงที่รับไว้:** ข้อกำหนดการใช้งานของ Vercel ระบุว่าแผน Hobby ใช้ได้เฉพาะงานส่วนตัวที่ไม่ใช่เชิงพาณิชย์ และนับ "การโฆษณาขายสินค้าหรือบริการ" เป็นเชิงพาณิชย์ portfolio ที่มีช่องทางติดต่อเพื่อรับงานจึงอยู่ในเขตสีเทา เอกสารของ Vercel เองแนะนำให้ติดต่อ support ถ้าไม่แน่ใจ เราเลือกรับความเสี่ยงนี้เพราะ portfolio ที่ติดต่อไม่ได้ไม่มีประโยชน์ และบันทึกไว้ตรงนี้เพื่อว่าถ้าวันหนึ่งถูกบังคับใช้จริง จะได้ไม่ต้องสืบใหม่ว่าเกิดอะไรขึ้น

นอกจากนี้ repo จะมี `docker-compose.yml` ที่รันระบบทั้งชุดได้ในเครื่อง เพื่อรองรับการเล่าว่าระบบย้ายไปติดตั้งบนเซิร์ฟเวอร์ของลูกค้าได้ โดยไม่ต้องจ่ายค่า VPS จริง และใช้เป็นฐานข้อมูลของ integration test ไปในตัว
